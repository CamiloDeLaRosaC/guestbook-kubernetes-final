# Guestbook — Docker and Kubernetes Final Project

Final project for IBM's **Introduction to Containers, Kubernetes and
OpenShift** course. The repository contains a containerized Go guestbook,
Kubernetes Deployments for versions 1 and 2, a Service, a Horizontal Pod
Autoscaler, and an evidence-collection script for rolling updates and rollback.

## Project files

- `v1/guestbook/Dockerfile`: multi-stage build with all required `COPY`
  instructions and `EXPOSE 3000`.
- `v1/guestbook/deployment-v1.yml`: initial deployment using CPU limit `50m`
  and request `20m`.
- `v1/guestbook/deployment.yml`: updated v2 deployment using CPU limit `5m`
  and request `2m`.
- `v1/guestbook/hpa.yml`: HPA targeting 5% CPU, from 1 to 10 replicas.
- `v1/guestbook/service.yml`: internal service used by the load generator.
- `submissions/task3_index_v1.html`: preserved v1 title and heading.
- `v1/guestbook/public/index.html`: updated v2 title and heading.
- `scripts/collect_ibm_cloud_evidence.sh`: runs the IBM Cloud and Kubernetes
  commands and saves the required terminal outputs in `submissions/`.

## Run in the IBM Skills Network lab

```bash
export MY_NAMESPACE=sn-labs-$USERNAME
ibmcloud cr region-set us-south
ibmcloud cr login
./scripts/collect_ibm_cloud_evidence.sh
```

The script deliberately captures live command output instead of including
fabricated registry names, image digests, HPA metrics, or ReplicaSet hashes.
These values are generated by the learner's temporary IBM Cloud environment.
